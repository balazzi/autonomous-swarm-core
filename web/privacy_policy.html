PROMINENT DISCLOSURE (App Store Compliance):
This application uses an autonomous multi-agent background framework to detect ransomware encryption behavior, memory tampering, and anomalous network activity. To do this it reads local device telemetry only: CPU thermal state, battery voltage behavior, memory pressure, file-operation entropy shapes, and packets traversing the on-device VPN tunnel you explicitly enable. All analysis happens on your device.

1. Data Collection and Zero-Third-Party Transmission

All security computation — lattice verification, topological file-system analysis, agent consensus — executes in local device memory under a zero-third-party-dependency model.

  • No exfiltration of personal content: file names, message text, keystrokes, contacts, and photos are never read, bundled, transmitted, or sold. The file-system module observes statistical shapes of I/O (entropy distributions), never file contents.
  • Hardware telemetry: thermal, voltage, and memory-pressure readings feed the on-device Resource Optimizer and are discarded after use.
  • Network tunnel: when you enable the optional local VPN, packets are inspected on-device by the Network Warden cohort and never leave the device except to their original destination.

2. Background Processing and Battery

The background service is throttled dynamically by the thermodynamic governor, which parks agent cohorts as temperature or battery drain rises. Target footprint: under 1% battery per hour in nominal conditions. Excluding the app from aggressive OEM battery savers is recommended so the governor — not the OS task killer — manages the schedule.

3. Permissions and Why Each Exists

  • Local VPN (Android VpnService / iOS NetworkExtension): optional; enables on-device packet inspection by the Network Warden cohort.
  • Storage / file access: optional; enables the topological ransomware interceptor to observe I/O entropy shapes. Denying it disables only that module.
  • Notifications: threat-isolation alerts in your language.

We do not request Accessibility Service access, SMS/call-log access, or device-admin privileges.

4. Subscriptions and Payments

Pro subscriptions are billed through Google Play Billing / Apple In-App Purchase on mobile, and through Stripe on the web PWA. We never see or store your card details. Cancelling returns the app to the permanent freemium tier; no data is deleted as a consequence.

5. Your Rights (GDPR / CCPA)

Because analysis is on-device, there is effectively no personal data held on our servers to export or delete beyond your subscription record (email + tier). Contact the controller above to access, correct, or delete that record.

6. Changes

Material changes to this policy will be surfaced in-app before they take effect.
